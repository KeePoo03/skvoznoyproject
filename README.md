# Прогнозирование успеваемости студентов (Сквозной ML-проект)

## Описание данных
Источник: UCI Machine Learning Repository — Student Performance (`student-por.csv`).
Данные содержат 649 записей об учениках курса португальского языка: демографические характеристики, семейный фон, учебные привычки, пропуски и промежуточные оценки (`G1`, `G2`).
Целевая переменная: `G3` — итоговая оценка за курс (от 0 до 20).

## Вопрос заказчика
- **Что предсказываем:** итоговую оценку студента `G3` по анкете, посещаемости и оценкам за первые два периода (`G1`, `G2`).
- **Кому и зачем нужна модель:** учебному отделу и преподавателям, чтобы в середине семестра заранее выявлять студентов с риском неуспеваемости, оказывать им поддержку и понимать, какие факторы сильнее всего влияют на итоговый балл.

## Подготовка данных (Этап 2)
Найденные проблемы в `student-por.csv`:
1. Нестандартный разделитель столбцов (`;` вместо `,`).
2. Промежуточные оценки `G1`, `G2` заключены в кавычки, часть записей имеет нулевую итоговую оценку (`G3 = 0`), что даёт левую асимметрию распределения.
3. Возможные лишние пробелы в текстовых категориях.

Исправление в `src/prepare.py`: перевод в стандартный CSV с разделителем `,`, удаление полных дубликатов (при наличии), очистка пробелов, проверка диапазонов оценок (`0..20`), возраста (`14..25`) и пропусков (`absences >= 0`). Результат сохранён в `data/clean.csv`.
